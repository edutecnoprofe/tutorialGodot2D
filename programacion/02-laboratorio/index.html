Laboratorio de diccionarios

Una interfaz con botones para probar las operaciones de un diccionario: añadir, buscar, borrar, ver claves, valores, tamaño y vaciar.

Objetivo

Al terminar tendrás un laboratorio donde escribes una clave y un valor (por ejemplo, país y capital) y pruebas con botones cada función del diccionario, viendo siempre su contenido.

Partimos de: Un proyecto vacío de Godot 4.6. Es la misma idea que el laboratorio de arrays.

⬇ Proyecto al empezar (.zip)⬇ Proyecto terminado (.zip)

Nodos y funciones

LineEdit

Campo de texto de una línea. Su texto está en .text.

Button + pressed

La señal pressed avisa cuando se pulsa el botón.

has() / erase()

Comprueba si existe una clave / la borra (devuelve true si estaba).

keys() / values() / size() / clear()

Claves, valores, número de parejas y vaciar.

Paso a paso

1Crea la interfaz

Crea una escena nueva con un nodo Control llamado Laboratorio. Dentro, arrastra: un Label Titulo, dos LineEdit (Clave y Valor), siete Button (Anadir, Buscar, Borrar, Claves, Valores, Tamano, Vaciar; el texto visible puede llevar ñ: «Añadir», «Tamaño») y dos Label: Resultado y Contenido. Guarda como laboratorio.tscn.

2Texto de ayuda en los LineEdit

Usamos LineEdit y no TextEdit porque solo necesitamos una línea. Selecciona Clave y en el inspector escribe clave en Placeholder Text; haz lo mismo con Valor. Es el texto gris que se ve cuando el campo está vacío.

3Añade el script

Selecciona Laboratorio y pulsa añadir script. Hereda de Control y se guarda como res://laboratorio.gd. Pulsa Crear.

4Conecta los botones

Selecciona Anadir, abre la pestaña Señales y haz doble clic en pressed(). El receptor es Laboratorio y el método, _on_anadir_pressed. Pulsa Conectar. Repite con los otros seis botones.

5El diccionario, los nodos y Añadir

Creamos el diccionario vacío y tipado (claves y valores String) y guardamos los nodos con @onready. mostrar() escribe el diccionario entero en Contenido. Añadir es una línea: si la clave es nueva se añade; si ya existía, se cambia.

extends Control

var datos: Dictionary[String, String] = {}

@onready var clave: LineEdit = $Clave
@onready var valor: LineEdit = $Valor
@onready var resultado: Label = $Resultado
@onready var contenido: Label = $Contenido


func mostrar() -> void:
	contenido.text = str(datos)


func _on_anadir_pressed() -> void:
	datos[clave.text] = valor.text
	resultado.text = "Guardado: " + clave.text
	mostrar()

6Buscar y Borrar

Buscar comprueba con has() antes de leer, para no dar error. Borrar usa erase(), que devuelve true si la clave estaba.

func _on_buscar_pressed() -> void:
	if datos.has(clave.text):
		resultado.text = clave.text + " → " + datos[clave.text]
	else:
		resultado.text = "No existe la clave " + clave.text


func _on_borrar_pressed() -> void:
	if datos.erase(clave.text):
		resultado.text = "Borrada: " + clave.text
	else:
		resultado.text = "No existe la clave " + clave.text
	mostrar()

7Claves, Valores, Tamaño y Vaciar

Cada uno es una línea. keys() y values() devuelven arrays, así que puedes recorrerlos o mostrarlos con str().

func _on_claves_pressed() -> void:
	resultado.text = "Claves: " + str(datos.keys())


func _on_valores_pressed() -> void:
	resultado.text = "Valores: " + str(datos.values())


func _on_tamano_pressed() -> void:
	resultado.text = "Tamaño: " + str(datos.size())


func _on_vaciar_pressed() -> void:
	datos.clear()
	resultado.text = "Diccionario vacío"
	mostrar()

8Ejecuta y añade

Ejecuta la escena con F6. Añade España → Madrid, Francia → París e Italia → Roma. El diccionario aparece completo debajo.

9Prueba Buscar

Escribe Francia en Clave y pulsa Buscar: aparece París. Prueba también con un país que no esté.

10Prueba Borrar y Claves

Escribe España, pulsa Borrar y después Claves: solo quedan Francia e Italia.

Resumen

  • datos[clave] = valor añade o cambia.
  • has() comprueba y erase() borra.
  • keys(), values(), size() y clear() hacen el resto.

Si algo falla

  • Al pulsar un botón no pasa nada. Comprueba en la pestaña Señales que su pressed está conectado (icono verde junto a la función) y que el método se llama igual en el script.
  • Error «Invalid access to property or key» al buscar. Lees una clave que no existe. Comprueba primero con has().
  • Error «Node not found: Clave». El nombre del nodo en el árbol debe coincidir exactamente con el de $Clave, mayúsculas incluidas.

Prueba tú

  • Añade un botón ¿Existe valor? que diga si un valor está en el diccionario (pista: datos.values().has(...)).
  • Haz que Añadir avise si la clave ya existía y se ha cambiado su valor.
  • Muestra el contenido una pareja por línea, recorriendo el diccionario con un for.
