Un inventario que cuenta

Un diccionario de String a int guarda objeto → cantidad. +1 suma o crea, −1 resta y borra al llegar a 0, y un for calcula el total.

Objetivo

Al terminar tendrás el inventario de un juego: escribes un objeto, lo sumas o lo gastas, y ves la lista y el total actualizados.

Partimos de: El proyecto de la práctica 1 (laboratorio). Añadimos una escena nueva, inventario.tscn.

⬇ Proyecto al empezar (.zip)⬇ Proyecto terminado (.zip)

Conceptos clave

Dictionary[String, int]

Claves de texto (el objeto) y valores enteros (la cantidad).

strip_edges()

Quita los espacios del principio y del final de un texto.

has() → += 1

El patrón comprobar y sumar: si existe, suma; si no, empieza en 1.

for clave in diccionario

Recorre todas las claves para mostrar y sumar.

Paso a paso

1Crea la interfaz

Crea una escena nueva con un Control llamado Inventario y guárdala como inventario.tscn. Dentro: un Label Titulo, un LineEdit Objeto (Placeholder Text: objeto), dos Button Mas y Menos (textos «+1» y «-1») y tres Label: Mensaje, Lista (grande, para varias líneas) y Total.

2Script y señales

Añade a Inventario un script res://inventario.gd que herede de Control. Después conecta la señal pressed de Mas y de Menos al nodo Inventario.

3El diccionario y el botón +1

El diccionario guarda objeto → cantidad. Al pulsar +1 limpiamos el nombre con strip_edges() y, si está vacío, salimos con return. Si el objeto ya existe, le sumamos 1; si no, lo creamos con valor 1.

extends Control

var inventario: Dictionary[String, int] = {}

@onready var objeto: LineEdit = $Objeto
@onready var mensaje: Label = $Mensaje
@onready var lista: Label = $Lista
@onready var total: Label = $Total


func _on_mas_pressed() -> void:
	var nombre := objeto.text.strip_edges()
	if nombre == "":
		mensaje.text = "Escribe un objeto"
		return
	if inventario.has(nombre):
		inventario[nombre] += 1
	else:
		inventario[nombre] = 1
	mensaje.text = "Añadido: " + nombre
	mostrar()

4El botón −1 y mostrar()

−1 avisa si el objeto no existe. Si existe, resta 1 y, si llega a 0, lo borra con erase(). mostrar() recorre el diccionario con un for: una línea por objeto y la suma de todas las cantidades.

func _on_menos_pressed() -> void:
	var nombre := objeto.text.strip_edges()
	if not inventario.has(nombre):
		mensaje.text = "No tienes " + nombre
		return
	inventario[nombre] -= 1
	if inventario[nombre] == 0:
		inventario.erase(nombre)
		mensaje.text = "Se acabó: " + nombre
	else:
		mensaje.text = "Gastado: " + nombre
	mostrar()


func mostrar() -> void:
	var texto := ""
	var suma := 0
	for nombre in inventario:
		texto += nombre + ": " + str(inventario[nombre]) + "\n"
		suma += inventario[nombre]
	lista.text = texto
	total.text = "Total: " + str(suma)

5Ejecuta y llena el inventario

Ejecuta con F6. Añade 3 pociones, 1 espada y 2 llaves (escribe el objeto y pulsa +1 las veces necesarias). El total es 6.

6Gasta un objeto

Escribe espada y pulsa −1. Llega a 0 y desaparece del inventario; el total baja a 5.

Resumen

  • Un diccionario String → int sirve para contar.
  • Comprueba con has() antes de sumar o restar.
  • Recórrelo con for para mostrarlo y calcular totales.

Si algo falla

  • Error al sumar: «Invalid operands 'Nil' and 'int'». Haces inventario[nombre] += 1 de un objeto que no existe. Comprueba antes con has() (o usa inventario.get(nombre, 0) + 1).
  • «Poción» y «poción» salen como objetos distintos. Las claves distinguen mayúsculas. Puedes guardarlo todo en minúsculas con nombre.to_lower().
  • La Lista sale en una sola línea. Revisa que cada línea termina con "\n" y que el Label Lista es alto.

Prueba tú

  • Reescribe el botón +1 en una sola línea con get(): inventario[nombre] = inventario.get(nombre, 0) + 1.
  • Añade un botón +5 y un SpinBox para elegir cuántas unidades sumar.
  • Muestra qué objeto tienes en mayor cantidad (recorre el diccionario guardando el máximo).
