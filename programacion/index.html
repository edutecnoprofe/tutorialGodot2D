Teoría de programación: diccionarios

Qué es un diccionario y cómo se usa, y cuatro prácticas que van creciendo hasta una pequeña base de datos que se guarda en un archivo.

1
Tutorial 1

Qué es un diccionario y cómo funciona

Un diccionario guarda parejas clave → valor. En vez de buscar por posición, como en un array, buscas por nombre: la clave.

2
Tutorial 2

Laboratorio de diccionarios

Una interfaz con botones para probar las operaciones de un diccionario: añadir, buscar, borrar, ver claves, valores, tamaño y vaciar.

3
Tutorial 3

Un inventario que cuenta

Un diccionario de String a int guarda objeto → cantidad. +1 suma o crea, −1 resta y borra al llegar a 0, y un for calcula el total.

4
Tutorial 4

Base de datos de alumnos

Un diccionario de diccionarios: cada código de alumno lleva a su ficha (nombre, curso y nota). Alta, edición, baja y consultas como en una base de datos.

5
Tutorial 5

Guardar y cargar en JSON

La base de datos de alumnos se guarda en un archivo JSON y se carga al abrir el programa: JSON.stringify, JSON.parse_string y FileAccess.
